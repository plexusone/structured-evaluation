# v0.1.0 Release Notes

**Release Date:** 2026-01-26

## Overview

Initial release of structured-evaluation, a reusable evaluation framework for LLM-as-Judge and multi-agent workflows.

## Features

### Evaluation Reports

For subjective quality assessments:

```go
report := evaluation.NewEvaluationReport("prd", "document.md")
report.AddCategory(evaluation.NewCategoryScore("clarity", 0.25, 8.0, "Well written"))
report.AddFinding(evaluation.Finding{
    Severity: evaluation.SeverityMedium,
    Title:    "Missing metrics",
})
report.Finalize("reviewer")
```

### Summary Reports

For deterministic GO/NO-GO checks:

```go
report := summary.NewSummaryReport("my-service", "v1.0.0", "Release")
report.AddTeam(summary.TeamSection{
    ID:   "qa",
    Name: "QA",
    Tasks: []summary.TaskResult{
        {ID: "tests", Status: summary.StatusGo, Detail: "100% pass"},
    },
})
```

### Severity Levels

Following InfoSec conventions:

| Severity | Blocking |
|----------|----------|
| Critical | Yes |
| High | Yes |
| Medium | No |
| Low | No |
| Info | No |

### DAG-Based Aggregation

For multi-agent workflows:

```go
results := []combine.AgentResult{
    {TeamID: "qa", Tasks: qaTasks},
    {TeamID: "security", Tasks: secTasks, DependsOn: []string{"qa"}},
}
report := combine.AggregateResults(results, "project", "v1.0.0", "Release")
```

### Renderers

- Box format for summary reports
- Detailed terminal format for evaluation reports

### CLI Tool

```bash
sevaluation render report.json --format=detailed
sevaluation check report.json
sevaluation validate report.json
```
