## [v0.14.0] - 2026-08-15

### Highlights

- Layered rubric classification: CriterionClass and EvaluationMethod taxonomies plus Class/Blocking/Evaluation fields on categories and criteria let a rubric separate advisory principle-based judgment from gating implementation checks instead of collapsing everything into one composite score
- RubricSet.JudgeInstructions carries cross-category evidence-discipline rules for the LLM judge prompt, complementing any per-category EvaluationPrompt
- RubricSet.Validate() enforces INV-3: a leadership_principle class must never be blocking, because advisory judgment cannot gate implementation

### Added

- `CriterionClass` type (`leadership_principle`, `specification_quality`, `implementation_readiness`, `deterministic_integrity`) and `EvaluationMethod` type (`deterministic`, `semantic`, `human`); `Class`, `Blocking`, and `Evaluation` fields on both `Category` and `Criterion` — all `omitempty`, so a v0.13.0-shaped rubric parses and validates unchanged ([`41e77fe`](https://github.com/plexusone/structured-evaluation/commit/41e77fe))
- `RubricSet.JudgeInstructions []string` — cross-category evidence-discipline rules (e.g. cite section/requirement IDs, do not reward length) applied across all categories ([`41e77fe`](https://github.com/plexusone/structured-evaluation/commit/41e77fe))
- `RubricSet.Validate()` INV-3 check: a category or criterion with `Class == ClassLeadershipPrinciple` must not set `Blocking`; regenerated `rubricset.schema.json` for the new fields ([`41e77fe`](https://github.com/plexusone/structured-evaluation/commit/41e77fe))
- `@plexusone/structured-evaluation@0.14.0`: Zod schemas and TS types regenerated for the rubric layering fields; also catches up the v0.13.0 claims fields (`sourceRole`, `minCorroboratingSources`, `corroborationCategories`, `maxClaimAge`) that were not regenerated at the time ([`572294c`](https://github.com/plexusone/structured-evaluation/commit/572294c))

## [v0.13.0] - 2026-08-10

### Highlights

- claims.Lint: evidence-integrity linting for claims reports — a verified claim must have a resolving URL and quote, sufficient independent corroboration, and a statistic that isn't stale, closing the gap that let a synthesized "$3B ARR" figure get marked verified
- ExternalValidation.Role (SourceRole) distinguishes primary/secondary-relay/secondary-analysis/self-reported sources; secondary-analysis and self-reported now require a corroborating relatedClaimId
- ClaimsCriteria gains MinCorroboratingSources and MaxClaimAge knobs, enforced by both claims.Lint and EvaluateClaims; both are opt-in and disabled by default
- BREAKING: ExternalValidation.AccessedAt and InternalValidation.ValidatedAt are now *time.Time so omitempty actually omits an unset value, instead of serializing the zero-value "0001-01-01T00:00:00Z" timestamp

### Added

- `claims.Lint(report) []LintFinding` and `sevaluation lint <claims.json>` — flags a verified claim missing a URL/quote (error), a value not found in the quote (warning), a verified derived/internal claim missing sources/evidence (error), and a subjective claim marked verified (warning) ([`d53be38`](https://github.com/plexusone/structured-evaluation/commit/d53be38))
- `sevaluation render <claims.json> --format=html\|json` and `sevaluation check <claims.json>` — claims-report support in the render/check commands ([`06b9fba`](https://github.com/plexusone/structured-evaluation/commit/06b9fba))
- `render/html` package: self-contained HTML renderer for `ClaimsReport`, grouped by verdict ([`7709583`](https://github.com/plexusone/structured-evaluation/commit/7709583))
- `SourceRole` type (`primary`, `secondary-relay`, `secondary-analysis`, `self-reported`) and `ExternalValidation.Role`; `SourceRole.RequiresCorroboration()`; `claims.Lint` rule `verified-role-needs-corroboration` ([`5ff6086`](https://github.com/plexusone/structured-evaluation/commit/5ff6086))
- `ClaimsCriteria.MinCorroboratingSources` and `CorroborationCategories`; `IsSufficientlyCorroborated(claim, criteria)`; `claims.Lint` rule `verified-insufficient-corroboration`; `EvaluateClaims` treats insufficiently-corroborated verified claims like needs-review for the report decision ([`18a5a0b`](https://github.com/plexusone/structured-evaluation/commit/18a5a0b))
- `ClaimsCriteria.MaxClaimAge`; `IsFresh(claim, criteria, now)`; `claims.Lint` rule `verified-stale-as-of-date`; `EvaluateClaims` treats stale verified claims like needs-review for the report decision ([`c01aa66`](https://github.com/plexusone/structured-evaluation/commit/c01aa66))
- `ExternalValidation.WithAccessedAt(t)` and `InternalValidation.WithValidatedAt(t)` chainable setters, mirroring `StatisticalDetail.WithAsOfDate` ([`4ee701b`](https://github.com/plexusone/structured-evaluation/commit/4ee701b))

### Fixed

- `ExternalValidation.AccessedAt` and `InternalValidation.ValidatedAt` are now `*time.Time` (was `time.Time`) so `omitempty` works; removes the render/html workaround that treated the zero-value timestamp as unset. No JSON schema change — the wire shape was already `string`/`format: date-time`, only the Go-side representation changed ([`4ee701b`](https://github.com/plexusone/structured-evaluation/commit/4ee701b))
